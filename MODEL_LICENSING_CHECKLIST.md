# Model licensing checklist before commercial distribution

- Verify the current OpenCV Zoo code and model-weight license for the exact YuNet and SFace files used.
- Verify any training-data restrictions or provenance statements for the exact pretrained weights.
- Keep license copies and notices with each release.
- Verify licenses of Python packages and any installer bundling tools.
- Do not claim a similarity score is a probability or identity proof.
- Obtain consent/permission and document retention/deletion procedures for biometric embeddings.
- Relevant discussion to review: https://github.com/opencv/opencv_zoo/issues/313
